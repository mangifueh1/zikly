# Zikly Design System

Zikly uses a warm, premium music aesthetic with a light canvas, strong charcoal text, and a restrained coral accent.

- Typography: system sans-serif, with tight heading tracking and readable body line height.
- Base colors: charcoal ink, warm paper, white surfaces, warm borders, coral accent, and muted green success.
- Spacing: 10/14/18/24/32/48 px scales.
- Radii: 10 px controls, 14–16 px cards and panels.
- Shadows: soft elevation for cards and strong elevation only for overlays or featured artwork.
- Icons: Lucide static icon font for navigation, actions, and status.
- Responsive rule: use two-column grids on mobile where artwork remains readable; collapse navigation and dashboard navigation on narrow screens.
